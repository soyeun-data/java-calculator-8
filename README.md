# java-calculator-precourse

## 구현할 기능 목록

### 핵심 기능
1. 입력된 문자열을 쉼표(,) 또는 콜론(:) 구분자로 분리
2. 입력된 문자열에서 "//"와 "\n"이 있다면 그 사이의 문자를 커스텀 구분자로 지정
3. 1,2번의 구분자로 분리된 문자열에서 숫자들을 정수로 변환 후 합을 구함
- 특이 케이스
    - 구분자 없이 숫자만 입력되었을 경우 숫자를 출력
    - 빈 문자열이 입력되었을 경우 0을 반환
### 입력
- 구분자와 양수로 구성된 문자열
- 입력 예외
    - 문자열에 양수가 아닌 값을 입력한 경우
    - 기본 구분자와 특수 구분자가 아닌 다른 구분자를 입력한 경우
    - 특수 구분자로 지정한 구분자가 아닌 다른 구분자를 입력한 경우
    - "//"와 "\n" 사이에 특정 구분자를 지정하지 않은 경우
    - 문자열에 공백이 있을 경우
    - 커스텀 구분자를 잘못 선언했을 경우
        - 커스텀 구분자에서 "//"는 있으나 "/n"은 없는 경우
        - 커스텀 구분자가 맨 앞부터 시작하지 않을 경우
### 출력
- 문자열 입력 안내 메시지
- 덧셈 결과 메시지
